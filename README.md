# Aravind's Portfolio

A modern, minimalist frontend developer portfolio built with React, Vite, and Framer Motion. Features smooth animations, Apple-inspired design, and responsive layout.

## 🎨 Design Features

- **Apple-inspired minimalism**: Clean typography, generous whitespace, and subtle animations
- **Color Palette**: 
  - Accent Red: `#DE322D`
  - Black: `#0C0C0C`
  - White: `#FFFFFF`
- **Typography**: Inter font family
- **Smooth animations**: Using Framer Motion for all transitions and scroll animations

## 🚀 Sections

1. **Landing Animation**: Eye-catching zoom-out animation with vertical split panels
2. **Hero Section**: Introduction with CTA buttons and social media links
3. **About**: Personal bio and technical skills
4. **Experience**: Timeline-style work history with reverse chronological order
5. **Projects**: Grid of featured projects with hover effects and live preview links
6. **FAQ**: Accordion-style frequently asked questions
7. **Testimonials**: Client testimonials in a card grid
8. **Contact**: Functional contact form with validation

## 🛠️ Tech Stack

- **React 19**: Latest React with hooks
- **Vite**: Fast build tool and dev server
- **Framer Motion**: Production-ready animation library
- **CSS Variables**: For consistent theming
- **Modern JavaScript**: ES6+ features

## 📦 Installation

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## 🎯 Development

The app will be available at `http://localhost:5173` after running `npm run dev`.

## 🎨 Customization

To customize the portfolio:

1. Update personal information in `Hero.jsx`
2. Add your experience in `Experience.jsx`
3. Add your projects in `Projects.jsx`
4. Update testimonials in `Testimonials.jsx`
5. Replace the placeholder CV file in `public/cv.pdf`
6. Update social media links in `Hero.jsx`
7. Modify color variables in `src/index.css`
